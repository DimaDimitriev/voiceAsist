# Голосовой ассистент

Запуск (Windows):

1. `pip install -r requirements.txt`
2. Скачайте модель `vosk-model-small-ru` с https://alphacephei.com/vosk/models и распакуйте в эту папку
3. Скопируйте `.env.example` в `.env` и заполните ключи
4. `python main.py`

Проверка разбора команд без микрофона: `python -m unittest`

Команды: погода, время, «что такое …», проверь почту, открой <программа>, включи музыку / пауза / следующий,
выключи компьютер (через 15 секунд, «отмена» отменяет), «пока» — выход.
